# 练记 1.3.0

记录力量训练、游泳和体测，支持 Android 8.0 及以上版本。训练记录离线保存，无需账号；联网仅用于检查和下载安装更新。

## 安装

把“lianji-1.3.0.apk”下载或传到安卓手机，用手机文件管理器打开并安装。如果手机询问是否允许该来源安装应用，按系统提示给当前文件管理器开启安装权限。

## 每次训练怎么记

1. 打开“训练”，进入当天训练；休息日会显示下一次训练。
2. 点某个动作的“第1组”，填写重量、次数和RIR，选择“完成并开始休息”或“直接完成”。
3. 当次训练只剩最后一组未完成时，按钮显示“完成本次训练”，保存后完成训练并停止休息通知，不再启动下一轮计时。若其他动作还有未完成组，则继续提供组间休息。

选择“完成并开始休息”后启动倒计时，可调整本组休息秒数（0–1800秒）；“直接完成”只保存，不启动新计时。动作的相邻组之间也可点击休息时间开始计时。点第2组时会带入上一组，可直接保存或小幅调整。
4. 自重动作的重量可以留空。重量也支持“空杆”，行走数量支持“1来回”。农夫行走的重量按每手记。
5. 做了额外一组，点“加一组”。动作旁的“···”可以编辑完整动作计划。
6. 训练页面底部记录游泳时间、距离、强度、睡眠与备注。

“计划”按周查看和补记；“记录”查看已经填写的训练；“身体”记录体重腰围，自动计算最近7天均重并显示体重趋势。

## 首次使用与个人计划导入

全新安装不自带个人训练计划或记录。首页可直接“导入Excel计划”，也可在“计划”页新建训练。覆盖安装更新仍保留手机上已有数据。

公开 Release 只提供安装包，不包含个人计划。可在“计划→导出计划 / Excel模板”获取空白模板，按表头填写后导入；导入前检查预览内容。只导入计划时取消“同时导入表内已填写记录”。

## 备份与换手机

顶部“备份与导出→导出完整备份”可生成JSON文件，包含全部计划、训练、游泳、体测和历史资料。请保存到自己选定的位置。

换手机时安装App，然后选择“备份与导出→更多选项→从完整备份恢复”。恢复按整次训练的最后修改时间合并：保留本机更新的版本，不清空本机记录。相同训练在两台设备分别编辑时，请先导出两份备份再合并。

也可单独导出训练CSV、体测CSV，用Excel打开。CSV用于查阅，完整恢复请使用JSON备份。Excel计划导入方式见下节。

数据只在本机保存；卸载App或清除应用数据会删除本机记录，请先导出完整备份。普通覆盖安装更新不会主动重置已经填写的记录。

## 当前版本

本版本为直接下载安装的版本，不依赖应用商店。已在Android 16模拟器上验证安装、数据保存与备份。尚未验证小米真机效果。休息计时同时显示在App内和通知栏，离开App后继续计时。首次开始休息时请允许通知权限；通知提供“结束休息”，点击通知可返回对应训练。到时显示休息结束提醒。若拒绝通知权限，通知栏不显示，仍可在App内查看。强行停止应用或重启手机会中断提醒。

## Excel导入与导出

进入“计划→导入Excel”，从系统文件选择器选择`.xlsx`文件，再选择训练计划工作表。支持按模板表头填写的训练记录表。旧版`.xls`需先另存为`.xlsx`。

导入前会展示新增训练、合并训练、动作数量、补入记录及冲突数量，确认后才写入。可以关闭“同时导入已填写记录”，只导入计划。相同日期和训练名称会合并，重复导入不会重复创建；已有记录有不同值时保留手机上的值，只补空白。工作表存在错误时会显示行号，修正后重新导入。

“计划→导出计划 / Excel模板”可以导出当前计划与记录，或下载空白模板。模板的核心列是日期、训练名称、动作、组数、次数下限和上限、单位、建议重量、RIR与休息秒数。日期可填写`2026-10-19`；按模板表头填写，不要删除必填列。也支持Excel日期单元格。

每次Excel导入前自动保留一份完整备份，可在同一菜单导出“导入前备份”。该备份会被下一次Excel导入更新；长期留存请自行导出完整备份。

## 编辑训练计划

在计划卡片点“编辑”，或进入训练后点“编辑训练计划”。可修改日期、名称、所属周、游泳安排，添加动作、调整顺序、复制训练至新日期，或移出训练计划。已移出的训练可从计划菜单找回。

动作可编辑名称、组数、次数范围、单位（次/秒/米）、起始重量、RIR、休息时间与备注；可选择同步到后续同名训练日。复制训练只复制计划，实际完成数据留空。

减少组数会保留已经填写的额外组。更换已有记录的动作名称或单位时，旧动作保留在历史区，新动作从空白开始。移除已有记录的动作也会保留历史，可恢复；未填写的动作可直接移除。完整JSON备份保留这些历史，Excel计划导出只包含当前有效计划。

## 1.2.1 更新

整次训练最后一个未完成组显示“完成本次训练”，保存后结束休息通知，并播放简短完成动画。编辑已完成记录不会重复播放。已移出的动作不影响训练完成判定。移除自由训练入口和专属分类，既有记录仍保留；训练计划可继续导入、新建和编辑。

## 应用内更新

1.3.0 起，打开 App 每天自动检查一次新版，也可点顶部“更新”。确认更新后显示下载进度，下载完成会校验安装包并打开系统安装器。首次需要允许练记安装应用，返回后继续安装。覆盖安装保留计划和记录，无需卸载。检查或下载失败时，可从 GitHub Release 页面手动下载。

更新检查只获取版本说明和安装包，不上传训练、游泳或体测数据。应用内更新需用户确认系统安装，无法静默安装。
