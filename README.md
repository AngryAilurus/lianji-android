# 练记

专门记录个人力量训练、游泳与体测的离线安卓应用。

## 打开项目

在Android Studio选择“Open”，打开本文件夹。应用源代码位于`app/src/main/java`，界面使用原生Android组件。支持Android 8.0及以上。

在Codex中可通过侧栏“添加项目”选择这个文件夹，后续继续在本项目中开发。

## 开发与构建

项目采用Android Gradle Plugin 8.13.0、Gradle 8.14.3、JDK 21、Android SDK 36。没有第三方运行库。训练数据保存在本机；网络权限仅用于获取 GitHub 版本信息与下载安装包。

```sh
./gradlew assembleDebug
./gradlew assembleRelease
./gradlew connectedAndroidTest
```

也可运行`python3 build.py`使用已安装的Android SDK直接构建，安装包生成在`dist/`。本机个人签名密钥已保留，后续更新请使用同一密钥。密钥不进入Git，也不包含在项目源码压缩包中。

## 目录

- `app/src/main/java/cn/lianji/training`：应用界面、SQLite存储、备份合并。
- `app/src/main/assets/seed.json`：空白初始化数据，不包含个人计划或记录。
- `app/src/androidTest`：数据保留、合成Excel导入与往返、计划编辑、事务回滚、SQLite持久化与备份恢复测试。
- `docs/使用说明.md`：安装、记录和备份说明。

1.2.0起，全新安装不预置任何个人计划、训练记录、体测或历史资料。用户可以导入Excel计划，或新建训练。覆盖安装更新保留已有数据。

公开仓库仅包含人工合成的测试资料。应用和 Release 不提供任何个人训练数据；用户在手机上创建或导入自己的计划。

1.1新增离线Excel计划导入、导出模板与完整计划编辑。导入先预览并按日期和训练名称合并，实际记录冲突保留本机值；编辑和移除动作保留已填写历史。

当前界面采用浅灰与钴蓝配色。逐组记录支持直接完成或开始组间休息，休息计时提供通知栏倒计时、提前结束和到时提醒；首次使用需允许通知权限。

## 应用内更新（1.3.0起）

打开应用每天自动检查一次，顶部“更新”可手动检查。新版本下载后校验 SHA-256、文件大小、包名、版本与签名，再调用系统安装器；首次安装更新需用户在系统设置允许练记安装应用。取消或下载失败不会影响记录，退出应用会取消当前下载。

更新源为本仓库最新正式 GitHub Release，仓库需公开。正式 Release 正文必须包含 `<!-- versionCode: 5 -->`（数值与本次 APK 的版本码一致），附件只能放一个正式 APK，并使用原签名、递增版本码。GitHub API 提供的附件 digest 用于校验。未打包任何 GitHub 凭据；网络不通时可从发布页手动下载。
